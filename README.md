# Silai Ghar PK Website

A responsive landing page for **Silai Ghar PK**, a Pakistani fashion brand. The page introduces the brand and provides links to its official website and social media profiles.

## Features

- Responsive layout for desktop and mobile screens
- Silai Ghar PK logo embedded directly in the HTML file
- Brand-inspired colors and styling
- Animated 3D-style Official Website button with centered text
- Social media and contact links
- Google Fonts (Montserrat) for typography

## Files

- `index.html` — main website page
- `README.md` — project information and setup instructions

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

No build tools or installation are required.

## Publish with GitHub Pages

1. Upload the website HTML file and this README to your GitHub repository.
2. Rename `silai_ghar_logo_theme.html` to **`index.html`** before uploading, so GitHub Pages can use it as the homepage.
3. Open the repository on GitHub and go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish the site. The published link will appear in the Pages settings.

## Notes

- An internet connection is needed to load the Google Fonts stylesheet.
- Check that all social media and website links in the HTML point to the correct accounts before publishing.

## Technology

- HTML5
- CSS3
- Inline SVG icons
